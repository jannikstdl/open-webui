## [0.3.0] - 10.06.2024

### Added

- **⚡ GPU-Unterstützung**: FI-TS AI Chat wird nun mit einer GPU von unserem Rechenzentrum betrieben, um schnellere Antworten zu ermöglichen.
- **📅 System Prompt-Variablen**: Neue Variablen hinzugefügt: '{{CURRENT_DATE}}' und '{{USER_NAME}}' für dynamische Prompts.
- **🖥️ PowerPoint-Unterstützung**: Die RAG-Pipeline unterstützt jetzt PowerPoint-Dokumente.
- **🐍 Ausführung von Python-Code**: Führe Python-Code lokal im Browser aus mit Bibliotheken wie 'requests', 'beautifulsoup4', 'numpy', 'pandas', 'seaborn', 'matplotlib', 'scikit-learn', 'scipy', 'regex'.
- **🧠 Experimentelle Memory-Funktion**: Geben manuell persönliche Informationen ein, die sich das LLM merken soll, über Einstellungen > Personalisierung > Memory.
- **📜 Zitate in RAG-Funktion**: Verfolge einfach den Kontext, der dem LLM zugeführt wird, mit zusätzlichen Zitaten in der RAG-Funktion.
- **👥 '@' Model-Integration**: Wechsele einfach zu bestimmten Modellen während einer Konversation
- **📂 Alle Chats archivieren**: Archiviere schnell alle Chats über Einstellungen > Chats.
- **✏️ Titel mit Doppelklick bearbeiten**: Doppelklicke auf Titel, um sie schnell und effizient umzubenennen.
- **✨ ..und vieles mehr**: Erkunde am besten gleich selbst die ganzen neuen Features!

### Changed

- **💾 Speicherung der Benutzereinstellungen**: Benutzereinstellungen werden jetzt auf dem Backend gespeichert, um Konsistenz auf allen Geräten zu gewährleisten.
- **🔄 Aktualisierte Benutzeroberfläche**: Die Chat-Oberfläche wurde mit Sprechblasen überarbeitet. Sie können jederzeit zum alten Stil zurückkehren, indem Sie zu Einstellungen > Benutzeroberfläche > Chat Bubble UI wechseln.

### Fixed

- **🔧 Bug Fixes**: Mehere Bugfixes um eine reibungslose Benutzererfahrung zu ermöglichen.
